# Smash Sacramento

Marketing site for Smash Sacramento — rage room, axe throwing, and splatter paint in Citrus Heights, CA.

Single-page static site. Bookings run through FareHarbor, waivers through Smartwaiver.

## Develop

It's plain HTML/CSS/JS — open `index.html` in a browser, or serve locally:

```
python3 -m http.server
```

## Deploy

Static host (Netlify, Vercel, GitHub Pages). `index.html` is the home page.
